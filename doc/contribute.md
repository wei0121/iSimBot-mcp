# Contribute

[Back to README](../README.md)

Bug reports, ideas, documentation improvements and pull requests are welcome.
Contributions are licensed under Apache-2.0.

## Issues

- Check existing issues before opening a new one.
- For bugs, describe what happened, what you expected and how to reproduce it.
- For suggestions, explain the problem you want to solve.
- Remove private information from logs, screenshots and examples.

## Pull requests

- Discuss larger changes in an issue before starting.
- Keep each PR focused on one change and explain its purpose.
- Describe how you verified the change and update relevant documentation.
- PRs need maintainer review before merging; please be open to feedback.

## Community

Be respectful, keep discussions constructive and focus feedback on the work.
